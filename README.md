# FEARLESS

A custom Discord bot tailored for the **Ruthless Fears** community.

## ⚔️ About The Community

**Ruthless Fears** is a community about the Roblox game *The Strongest Battleground*, owned by **RDS**. This bot handles internal automation and management specific to the community's needs.

🔗 **[Join the Discord Server](https://discord.com/invite/aEUyubPVV3)**

## 🛠️ Built With

*   [Bun](https://bun.sh) - A fast all-in-one JavaScript runtime.
*   [TypeScript](https://www.typescriptlang.org/) - Typed superset of JavaScript.
*   [discord.js](https://discord.js.org/) - The library used to interact with the Discord API.
