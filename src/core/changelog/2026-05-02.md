# FEARLESS Bot Update - May 2, 2026

## 🚀 Improvements

*   **Snipe Command:** Images in the `/snipe` command will no longer disappear! We've improved how the bot handles deleted images by saving a copy immediately, ensuring that you can always see the sniped content even if Discord's links expire.

## 🛠️ Bug Fixes

*   **Economy & Shop:** Fixed an issue where XP purchases (like the 100 XP and 500 XP items) were missing from your `/receipt`. All previous and future XP buys are now properly recorded and tracked!
*   **Command Stability:** Fixed a bug where certain "hidden" admin commands could cause the bot to crash while loading. Commands should now respond much more reliably.
*   **Message Logs:** Fixed a bug in the deletion logs where images would sometimes fail to load or show up blank. The bot now properly saves and attaches these images so they are always visible in the log channels.
*   **Member Updates:** Cleaned up the member logs to stop empty notifications from appearing. We also fixed a bug where swapping roles (taking one and giving another at the same time) wasn't being logged correctly.
